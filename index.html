Hisaab Guru

One site, two modes: Khata Guru for shopkeepers and SpendWise for students.

Open Hisaab Guru
Important: Hisaab Guru is a Python Streamlit application. The main application file is app.py. GitHub Pages can host this index.html, but it cannot run the Python/Streamlit backend, Ollama, or Whisper itself. For the full application, run streamlit run app.py on a machine/server that supports Python.
